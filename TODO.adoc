== Engine adapters

* *grale-elk: map `minlen` / `weight`.* Neither is translated to an ELK option
  (today both are flagged `UNSUPPORTED`); `doc/grale-elk.adoc` lists candidate
  mappings (`elk.layered.*` priority/spacing — only loosely comparable, which
  is why this needs deliberate tuning, not a mechanical mapping).
* *grale-elk: ports.* ELK has a rich first-class port model
  (`elk.portConstraints` etc.); the adapter could map grale's
  `ports` + `fromPort`/`toPort` instead of warning `UNSUPPORTED`.

  and the spec's node-size estimation note (Roboto 16 px advance table) should
